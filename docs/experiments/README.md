# Experimentos

Este directorio contiene la documentación de cada experimento de arquitectura frontend.

En la **Fase 0** este directorio está vacío a propósito: los experimentos se implementarán y documentarán en fases posteriores.

Experimentos planificados:

- React Monolith
- Angular Monolith
- Web Components
- Lit
- Microfrontends

Cada experimento documentará, como mínimo: alcance funcional, decisiones específicas del enfoque, metodología de medición y limitaciones.

> Reglas: documentación en español; todos los experimentos deben implementar requisitos funcionales equivalentes del dominio Operations Hub.
