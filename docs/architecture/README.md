# Documentación de arquitectura

Este directorio contiene la documentación de arquitectura del proyecto: principios, diagramas y análisis por experimento.

En la **Fase 0** este directorio está vacío a propósito: no existe ninguna implementación que documentar.

Contenido previsto para fases posteriores:

- Diagramas de arquitectura por experimento.
- Análisis de decisiones estructurales de cada enfoque.
- Notas sobre el diseño del dominio compartido (Operations Hub).

> Regla: toda la documentación de este directorio se escribe en español.
